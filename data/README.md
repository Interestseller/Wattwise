# data/ folder — Put Your Energy Dataset Here

## ⚡ Quick Start

Place your electricity consumption CSV file in this folder and name it:

```
energy_dataset.csv
```

Then open `config.py` in the project root and confirm that these settings
match your file:

```python
DATASET_PATH    = "./data/energy_dataset.csv"
TIMESTAMP_COLUMN = "DateTime"
TARGET_COLUMN   = "Global_active_power"
```

You can also change these settings interactively in the Streamlit sidebar
without editing any code.

---

## Supported CSV Format

The minimum required columns are a **timestamp** and an **energy/power** value:

```csv
DateTime,Global_active_power
2024-01-01 00:00:00,1.25
2024-01-01 01:00:00,1.18
2024-01-01 02:00:00,1.42
```

Additional columns (voltage, current, appliance sub-meters, weather, etc.)
are used automatically when present.

### Column naming

Your file does not need to use these exact column names.  When you launch the
application you will be prompted to select the correct timestamp and target
columns from a drop-down list.

### Supported units

| Unit | Description                       | Notes                                |
|------|-----------------------------------|--------------------------------------|
| kW   | Kilowatts (instantaneous power)   | Most common for smart-meter exports  |
| W    | Watts (instantaneous power)       | Divide by 1000 to convert to kW      |
| kWh  | Kilowatt-hours (energy)           | Already energy; no conversion needed |
| Wh   | Watt-hours (energy)               | Divide by 1000 to convert to kWh     |

You will be asked to specify the unit if it cannot be detected automatically.

### Sampling frequency

The app works with any consistent sampling interval (1 minute, 15 minutes,
1 hour, daily, etc.).  Very high-frequency data (sub-minute) will be
resampled automatically.  Very sparse data (weekly or coarser) may limit
available features.

## Obtaining a Real Dataset

The following publicly available datasets are suitable for this application.
Download them separately and place the relevant file here.

| Dataset | Description | URL |
|---------|-------------|-----|
| UCI Individual Household Power Consumption | 2-year, 1-minute household data | https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption |
| UK Power Networks Open Data | Smart meter half-hourly data | https://data.london.gov.uk/dataset/smartmeter-energy-use-data-in-london-households |

> Always check the dataset's licence before using it in a project or
> publishing results.

## Demo Dataset

A small synthetic demonstration dataset (`demo_energy_dataset.csv`) is
included in this folder.  It is generated by a script and contains
realistic-looking but entirely artificial energy readings.

**Do not treat demo-dataset results as real household consumption.**  The
demo exists only to let you explore the application interface before you
supply your own data.

---

## Privacy Notice

**Do not commit real household energy data to a public repository.**
Real consumption data can reveal when a home is occupied or unoccupied
and may be considered personal data under applicable privacy regulations.

The `.gitignore` at the project root excludes `data/*.csv` (except the demo
file) to help prevent accidental commits.
